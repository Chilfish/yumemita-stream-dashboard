## 隐式状态机首轮实施

### 操作

- 授权：摘要查询失败不再跳过会员门禁；packs 用 payload 的 `availability`；会员 key 改常数时间比较，未配置时 API 返回 503；`.md` 的 `HEAD` 复用 `GET` 判定；错误 `?key=` 不再关闭缓存；会话密钥与登录密码分离且必填；管理端路径改为显式清单并规范化尾斜杠；无 `Origin` 的写请求要求 `Authorization` 或同源 `Sec-Fetch-Site`。
- 缓存与错误态：新增 `src/lib/cache-tags.ts`，`astro.config.mjs`、`daily-update` 与 `purge-cache` 共用；purge 端点把「缓存关闭」返回为 `skipped`；组页与成员日历页改为查询成功后写缓存，500 不再被 404 覆盖。
- 生命周期：`isLive` 统一直播判定并把频道检查窗口收到 12 小时；`hasStream` 优先于取消；日程匹配按 key 稳定排序，PATCH 合并保留手工字段；空 `source_schema` 统一按 v1；组页读数把会员限定与未抓取都显示为「—」。
- 客户端：日历页共用单一 `now`；`setSearchParams` 支持函数式更新；路由兼容层监听 `popstate` 与 `astro:page-load`；侧栏主题改用 `useSyncExternalStore`；`useTranscript` 的 `force` 只作用于一次请求；不可用子视图回退概览；分享卡片单独显示生成错误；场次空状态区分「还没有场次」与「筛选后为空」；未知成员 id 不再筛空页面。
- 管线：`update-plan` 新增 `expiredIds` 并在运行摘要输出；`backfill-owner-chats` 用空 `ownerChats` 标记「已确认无主播发言」；ingest 异常时把报告关闭为 `failed`；`withinGrace` 不再对结束时间在未来的场次写不可用哨兵；发布按远端大小对齐时写入摘要记录。
