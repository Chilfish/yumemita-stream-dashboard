## 接入 `@chilfish/devkit@0.1.1`（B51）

上游 `0.1.1` 补齐了 ymmt 迁移所需的五项能力（[devkit#5](https://github.com/Chilfish/devkit/issues/5)）：`env/online`、`dev server --local`、`describe` 标签、`requireEnv`、`ensureDevServices` 的 `databaseUrl` / `endpoint` 覆盖。

### 改动

- 新增 `scripts/dev.config.ts`，把数据库、代理、桶、迁移目录、日志目录与 dev server 收敛到一处。
- `scripts/cli.ts` 改用 `buildCli({ config, version, groups, rootCommands, labels })`；`describe` 的退出码与全局选项文案仍为中文，和改造前逐字段一致。
- `scripts/commands/dev-group.ts` 用 `createDevCommands(devkit, { serverLocalFlag: true, strings })` 生成 `dev` 组，保留原有中文帮助与 `--local`。
- 删除 `scripts/lib/cli/*`、`scripts/lib/env.ts`、`online-env.ts`、`local-config.ts`、`dev-services.ts`、`dev-silo.ts` 与 `scripts/commands/dev/*`。
- 业务命令只改基础设施导入：`@scripts/lib/cli/*` → `@chilfish/devkit/cli`，线上切换 → `@chilfish/devkit/env`，本地编排 → `@chilfish/devkit/local`，SILO → `@chilfish/devkit/storage`。
- `publishStatePath` 移到既有的 `scripts/lib/publish-state.ts`；远端 R2 解析仍留在 `object-storage.ts`。
- 删除重复的单测（CLI runtime / env / local-config 已在 devkit 覆盖），`publishStatePath` 断言并入 `publish-state.test.ts`。

### 验证

- `bun run ymmt describe --json` 与改造前快照逐字段一致（仅 `version` 除外）。

### 阻塞

本地链路 `bun run dev` 在拉起代理时失败：

```
Background proxy entry not found. Build the package or run from source with Bun.
```

devkit 0.1.1 打包后 `resolveProxyEntry()` 用 `new URL('../bin/proxy.js', import.meta.url)`，从 `dist/local-*.js` 解析到包根的 `bin/proxy.js`，而发布文件在 `dist/bin/proxy.js`。已提 [devkit#6](https://github.com/Chilfish/devkit/issues/6)。
