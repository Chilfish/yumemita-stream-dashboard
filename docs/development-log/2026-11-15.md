# 2026-11-15

## 用 claude-seo 审计线上站点

试跑 [claude-seo](https://github.com/AgriciDaniel/claude-seo)（MIT，Claude Code 的 SEO 插件）对 `https://ymmt.chilfish.top` 做外部审计，结论落成 [research/seo-audit-2026-11-15.md](../research/seo-audit-2026-11-15.md)，待办登记 backlog B38。

### 做法

不装插件（本机以 Claude Code 之外的 agent 为主），只复用它的脚本层：`git clone --depth 1` + `uv venv` + 装 `requests / beautifulsoup4 / lxml / trafilatura`，然后直接跑 `sitemap_discovery.py`、`transport_check.py`、`agentic_check.py`、`page_checks.py`。判断层（评分权重、优先级、报告结构）按 `skills/seo/SKILL.md` 的 playbook 执行。另写一轮抽样巡爬：`sitemap.xml` 分桶、每桶随机 8 条、共 42 条。

### 结果

健康分约 82/100。结构层面很干净：0 非 200、0 重复标题/描述、canonical 与 JSON-LD 全覆盖、404 是真 404、`.md` 视图带 `X-Robots-Tag: noindex` + `Content-Signal` + `rel="alternate"`。

两个真问题：

- `http://ymmt.chilfish.top/` 返回 200 且 `CF-Cache-Status: HIT`，不跳 HTTPS，同时无 HSTS。curl 与 `transport_check.py` 两路证据一致。
- `/gallery` HTML 未压缩 2.07 MB，越 Googlebot 解析上限；成员页 / streams / trends / transcripts 普遍 1.0–1.7 MB。内联脚本只有 6.5 KB，体积全在 SSR 出来的 DOM 本身。

其余为中低优先：图片缺 `width`/`height`、`/calendar` 与 `/about` 无 `og:image`、响应头 `Content-Type` 不带 charset、成员页只有 `BreadcrumbList` 缺 `Person`。

### 坑

自写巡爬第一版把 `resp.text` 直接交给 bs4，中文标题长度被算成 3 倍。原因是线上 `Content-Type: text/html` 没带 `charset`，requests 退回 latin-1 解码——这本身也是要修的项（M5）。改成按 UTF-8 解码后数据才干净。

### 未验证

PSI 无 API key 直接 429，claude-seo 的 `pagespeed_check.py` 这条路没跑通。`www.ymmt.chilfish.top` 的 TLS 握手失败疑似本机 DNS 产物（解析到 `28.0.2.188`），需换网络复核。

LCP 拆解显示 TTFB 119 ms、下载 191 ms、**元素渲染延迟 1,995 ms**——图片很早就下完了但画不出来，且 `lcp-discovery-insight` 三项全绿。所以「压图片体积」救不了 LCP，得先录 trace 定位那 2 秒。这条不写结论，只写待查。

### 新发现（静态审计看不到的）

- **首页 3,440 KB 载荷里 2,392 KB 是字体**：`src/styles/app.css` 的 `@import "@fontsource-variable/noto-sans-sc"` 带 101 个 woff2 子集（4.29 MB），首页命中 48 个。同时 `Layout.css` 未压缩 390 KB 里近一半是两个字体包的 `@font-face` 声明。
- **缩略图 `Cache-Control: max-age=14400`（4 小时）**，而同一份报告里 `/_astro/*` 的 CSS 与字体都是 1 年 immutable。R2 里的派生图是不可变对象，这里没对齐。

- **19 处 `color-contrast` 不达标**，集中在侧栏 `text-ink-3` 与 `text-body`。
- **`unused-javascript` 的 1,593 KB 是浏览器扩展污染**（两条 `chrome-extension://` 加起来 1.3 MB），站点自身只有 113 KB。以后跑 Lighthouse 要用干净 profile。

### 记录

- 报告里 `structured-data` 是 `score: null`，Lighthouse 13.5 把它改成 `manual` 模式，属正常，不是站点问题。
- 桌面模拟 10 Mbps 下字体就吃掉 2.36 MB，移动端 1.6 Mbps 会差一个量级；这份报告不能代表移动体验，待补 mobile preset。

## 按审计结论修复

改动落在 [research/seo-audit-2026-11-15.md](../research/seo-audit-2026-11-15.md) 第五节的「修复记录」，这里只记判断过程与踩到的坑。

### 中间件

`forceHttps()` 放在 `onRequest` 最前面。线上 `http://` 请求本来就会进 Worker（响应头里有 `x-response-time`），所以不必依赖 Cloudflare 的 Always Use HTTPS 开关。**localhost 要豁免**：`astro dev` 和 `astro preview` 都是 http，不豁免会把自己挡住。

HSTS 只在 `https:` 下发，本地不下发——`max-age` 一旦落到 127.0.0.1，浏览器会把本地开发全转成 https。

charset 只补 `text/*` 且未带参数的；`.md` 路由自己给了 `text/markdown; charset=utf-8`，正则 `^text\/[^;]+$` 不会重复追加。

### 字体

去掉 `@fontsource-variable/noto-sans-sc` 是这轮最大的收益，也是唯一有观感代价的改动：中日文从 Noto Sans SC 换成系统字体（PingFang / Hiragino / Noto Sans CJK / 微软雅黑）。`ui-design/README.md` 原本写的就是「Noto Sans → 系统 sans」，系统栈不算偏离规范，但要接受不同平台的字形差异。拉丁与数字仍自托管，`tabular-nums` 不受影响。

顺带把包从 `package.json` 移除——留着会让下一个人以为还在用。

### 对比度

没有凭感觉调。先算：`#8a8a92` 在侧栏底 `#efe9ee` 上 2.86:1，在卡片白底 3.43:1，都不到 4.5。试到 `#66666f` 才三处全过（4.75 / 5.68 / 5.11），再浅一档 `#6b6b74` 在侧栏只有 4.41。`--sidebar-foreground` 的 64% 混色算出来 4.35:1，差一点点，提到 72% 到 5.48:1。

### 一处初版审计写错了

Lighthouse 的 `image-delivery-insight` 说图片选档过大、浪费 491 KB。查 `configSettings.screenEmulation.deviceScaleFactor` 是 **1.75**——753 CSS px 显示位需要 1318 物理像素，选 1280w 完全正确。`srcset`/`sizes` 在各调用点都写对了，**没有改**。审计文档里那条已改成更正说明，避免下次照着错的方向改。

### 没做的

- 缩略图缓存 4 小时：`scripts/lib/object-storage.ts` 已经写明 Bun 的 S3 写入只能给 `Content-Type`，`Cache-Control` 得在 Cloudflare 加 Cache Rule。代码层改不了。
- `/gallery` 的 1.71 MB island props：查清了体积来源（不是 DOM 铺满，是整份 1,837 行塞进 `props`），但改成「SSR 首屏 + 客户端分页拉取」要新端点与三态，属于功能改动，单独立项 B39。
- LCP trace 与 mobile preset：都要浏览器侧条件，本机复现不了线上网络。

### 验证

- `bun run check`：0 errors，544 tests passed（新增/更新 3 条 SEO 断言）。
- `bun run build` 通过；产物 `@font-face` 101 → 8，woff2 4.29 MB → 430 KB，CSS 390 KB → 282 KB。
- `astro dev` 实跑：`/` 的 `@type` 为 `Organization, WebSite`；`/arale` 为 `Person, Organization, BreadcrumbList`；`/about`、`/calendar` 都有 `og:image`；`Content-Type: text/html; charset=utf-8`；`.md` 未重复追加；两条长标题 56 字。本地 127.0.0.1 不跳转、不下发 HSTS。
- **未验证**：线上 301 与 HSTS 要部署后复查；对比度要重跑 Lighthouse 才能确认归零。
