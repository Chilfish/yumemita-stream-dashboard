# 2026-11-23

## `bangdream` 改为手动添加

### 背景

每日更新把 `@bang_dream_official` 的 423 场直播全部判为新场次，开始逐场拉元信息。原因是 `data-sources.json` 里 `bangdream` 标的是 `sync: "filtered"`，但 `filtered` 的两段过滤（标题粗筛 + 简介 cast）从未接进 `data fetch`，`data update` 只按 `sync !== 'manual'` 分流，实际等同于整频道同步。

### 决定

- `bangdream` 的 `sync` 改为 `manual`：每日更新不拉频道列表、不写日程、不补 VSTATS。
- 不回补历史场次，本地保留已入库的 29 份 pack。
- 删除 `include` 配置（没有账号再使用 `filtered`），`participants: "cast"` 保留作手动添加时的解析回退。
- 中断的抓取没有落盘新 pack：`data/bangdream` 仍是 29 份，`manifest` 仍缺失。

### 改动

| 文件 | 改动 |
| --- | --- |
| `data-sources.json` | `bangdream.sync: filtered → manual`；删除 `include`；更新 `scope` / `note` |
| `scripts/commands/data/official.ts` | 命令说明改为覆盖 `bangdream` 母频道与第三方账号 |
| `tests/scripts/config.test.ts` | 新增配置断言：`bangdream` 为 `manual`、无 `include`、不在自动同步列表 |
| 文档 | [official-channels.md](../planning/official-channels.md) §9.6 记录决定；§2 / §3.2 / §4 / §5 / §9.4 / §10 同步口径；[cli.md](../engineering/cli.md) 手动添加一节补 `bangdream` |

### 验证

- `bun run ymmt data update --dataset bangdream --dry-run`：报「找不到可自动同步的 dataset：bangdream」，可用列表为 `nonoka, arale, ritsu, miyako, yuno, yumemita`，`bangdream, other` 走手动命令；退出码 1，符合预期。

## Agent 场次搜索接口 `/api/streams`

### 背景

`llms.txt` 只列出成员与每成员最近 4 场，Agent 想找「某个主题 / 某段时间 / 某类内容」的场次时只能遍历 sitemap 或逐个成员页抓取。页面上的 `q` / `type` / `sort` 是浏览器端过滤整份列表，没有对外接口。

### 设计

- 一个跨成员端点 `GET /api/streams`，参数与页面筛选口径一致：`q`（标题 / videoId / 日期子串）、`member`（逗号分隔，命中 owner 或参与者）、`type`、`from` / `to`（JST 闭区间）、`availability`、`sort` / `dir`、`limit` / `offset`。
- 返回 `{ schema, query, total, count, nextOffset, streams }`；`query` 是归一化后的参数，`streams` 每项是现有 `StreamSummary` 加 `type` 与 `links.html` / `links.markdown` / `links.pack`。
- 内容类型筛选直接把 `classify.ts` 的规则源码翻译成 PostgreSQL `~`，避免页面与接口两套分类。
- 会限场次仍可搜索，但指标沿用 `maskMemberOnlyMetrics`（0 / null / `masked: true`）；按指标排序时整行推到末尾。
- 非法参数返回 400 与字段名；缓存 300 秒 + `streams` tag，`publish purge --dataset` 一并失效。

### 改动

| 文件 | 改动 |
| --- | --- |
| `src/lib/stream-search.ts` | 参数解析、搜索条目组装 |
| `src/pages/api/streams.ts` | 新端点；`Link` 指向 schema |
| `src/db/queries/streams.ts` | `WHERE` / `ORDER BY` / 分页与总数查询 |
| `src/lib/classify.ts` | 导出 `CONTENT_TYPE_RULES`，页面与 SQL 共用 |
| `src/lib/json-schema.ts` | 新增 `stream-search.v1` schema 与编译期字段校验 |
| `src/lib/agent-llms.ts` | `llms.txt` 加搜索入口、schema 与推荐读取顺序 |
| `scripts/commands/publish/purge.ts` | `--dataset` 追加 `streams` tag |
| `src/types/dataset.ts` | `StreamSearchItem` / `StreamSearchResponse` |
| 测试 | `tests/lib/stream-search.test.ts`、`tests/db/queries/stream-search.test.ts`；schema / llms 测试补充 |
