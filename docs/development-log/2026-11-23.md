# 2026-11-23

## `bangdream` 改为手动添加

### 背景

每日更新把 `@bang_dream_official` 的 423 场直播全部判为新场次，开始逐场拉元信息。原因是 `data-sources.json` 里 `bangdream` 标的是 `sync: "filtered"`，但 `filtered` 的两段过滤（标题粗筛 + 简介 cast）从未接进 `data fetch`，`data update` 只按 `sync !== 'manual'` 分流，实际等同于整频道同步。

### 决定

- `bangdream` 的 `sync` 改为 `manual`：每日更新不拉频道列表、不写日程、不补 VSTATS。
- 不回补历史场次，本地保留已入库的 29 份 pack。
- 删除 `include` 配置（没有账号再使用 `filtered`），`participants: "cast"` 保留作手动添加时的解析回退。
- 中断的抓取没有落盘新 pack：`data/bangdream` 仍是 29 份，`manifest` 仍缺失。

### 改动

| 文件 | 改动 |
| --- | --- |
| `data-sources.json` | `bangdream.sync: filtered → manual`；删除 `include`；更新 `scope` / `note` |
| `scripts/commands/data/official.ts` | 命令说明改为覆盖 `bangdream` 母频道与第三方账号 |
| `tests/scripts/config.test.ts` | 新增配置断言：`bangdream` 为 `manual`、无 `include`、不在自动同步列表 |
| 文档 | [official-channels.md](../planning/official-channels.md) §9.6 记录决定；§2 / §3.2 / §4 / §5 / §9.4 / §10 同步口径；[cli.md](../engineering/cli.md) 手动添加一节补 `bangdream` |

### 验证

- `bunx vitest run tests/scripts/config.test.ts`：2 条通过。
- `bun run ymmt data update --dataset bangdream --dry-run`：报「找不到可自动同步的 dataset：bangdream」，可用列表为 `nonoka, arale, ritsu, miyako, yuno, yumemita`，`bangdream, other` 走手动命令；退出码 1，符合预期。
- `bun run check`：exit 0；58 个测试文件通过，lint 0 errors（32 条既有 warning）。
