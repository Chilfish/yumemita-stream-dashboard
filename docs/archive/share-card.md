# 直播日程分享卡片设计

> **已归档（2026-11-08）**：分享卡片已实现；实现见 `src/components/dashboard/calendar/share-card.tsx`。
> 目标：从「直播预定」时间线生成一张适合发到社交平台的独立卡片，而不是截取页面。
> 卡片是真实的 React + Tailwind 节点，固定 1200px 宽、高度由内容决定；导出时用 `modern-screenshot` 抓 DOM，而不是手写 SVG。

## 1. 信息层级

从上到下只有四层：

1. **身份**：`夢限大みゅーたいぷ` + `直播日程`。
2. **范围**：`11 月 7 日 – 11 月 8 日 · JST`。
3. **安排**：按 JST 自然日分组，最多 7 场；每组有「今天 / 明天 + 日期 + 场次数」。
4. **落款**：`夢限大みゅーたいぷ · ymmt.chilfish.top`，右侧小字 `LIVE SCHEDULE`。

每场只保留：时间、成员头像、成员名、内容类型（图标 + 文案）、标题。
不显示状态徽标、封面、底部成员头像行或生成时间。

## 2. 布局

- 卡片宽度 `w-[75rem]`（1200px），高度随内容自然增长，不写死 canvas 高度。
- 页面内边距：`px-24 pt-20 pb-16`。
- 列表容器：`mt-10 rounded-3xl border border-white/70 bg-white/55 px-12 py-2`。
- 每场用 flex：时间列 `w-20 text-center`、头像 `size-12`、文本 `flex-1`；间距 `gap-4`、`py-4`。
- 时间用 `pt-7` 与标题第一行对齐；头像 `self-center` 跟随整个文本块。
- 标题 `text-3xl leading-9`，成员名 `text-lg`，时间 `text-2xl`。
- 类型图标 `size-4` + `text-base`，放在成员名右侧，水平居中于同一行。
- 日期头 `py-3`，分隔线用 `border-stone-700/10`，不再使用固定行高。

## 3. 颜色

- 背景使用官方 `public/share/bg_member_list.webp`，`object-cover` 铺满，再叠一层 `bg-white/15`。
- 文本使用 Tailwind `stone` 色阶：`stone-800` / `stone-500` / `stone-400`。
- 列表容器是白色 55% 的磨砂面板，只靠透明度和 1px 白描边分层，不用重阴影。
- 成员色只用于头像与时间轴点；不铺大面积色块，也不叠加紫色光晕。

## 4. 内容规则

- 只显示未取消的日程。
- 标题为空时显示「待定」。
- 超过 7 场时只展示前 7 场，并在列表末尾标注「还有 N 场未显示」。
- 封面不进入卡片；即使日程数据里有 `thumbnail_key`，也不读取、不展示。

## 5. 导出流程

1. 点击时间线右上角的分享图标。
2. 打开预览弹窗，同时在屏幕外挂载一个 1200px 宽的 `ShareCard` 节点。
3. 等 `document.fonts.ready` 和两帧 `requestAnimationFrame` 后，用 `domToBlob(node, { scale: 1 })` 导出 PNG。
4. 预览、下载、复制都复用同一个 Blob；关闭弹窗时撤销 object URL。
5. 生成失败或浏览器不支持剪贴板时给出明确提示，不静默失败。

## 6. 移动端导出保护（2026-11-09）

- 卡片根节点声明 `text-size-adjust: 100%`，避免移动端浏览器字体放大后把标题顶出容器。
- 标题最多三行、`wrap-anywhere`；成员名 `truncate`，长标题不再横向溢出。
- 预览弹窗的图片区改为可收缩滚动（`min-h-0 flex-1`），小屏上底部按钮始终留在视口内；图片可点开原图。
- 预览图按弹窗宽度缩放，导出 PNG 仍是 1200px 宽。

## 7. 验证清单

- 1 / 2 / 7 场时都能完整展示，标题最多三行。
- 时间在列内水平居中，并与标题第一行对齐。
- 成员名、类型图标、标题左对齐；头像随文本块垂直居中。
- 头像缺图时用成员色首字兜底。
- 官方背景加载失败时有粉色渐变兜底。
- 导出 PNG 与弹窗预览一致。
