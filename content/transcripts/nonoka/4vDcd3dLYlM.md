## 1. 开场：ゲーミングコメント欄与「コカ・コーラ」

入场照旧。这一场她先花了几分钟**摆弄画面**：把**评论区调成彩虹配色**（她的说法是「把大家调成电竞配色哦」），随后弹幕齐刷「大家脸色好差啊」「评论区一片漆黑笑死」「电竞配色帮大忙了」——她自己也承认「大家脸色好差啊。真的。都变铁青了」，然后又去折腾摄像机的取景。

接着是**频道的订阅人数显示**：她想让订阅数以「登録者数」的样式露出来，一边嘀咕「不想显示成『订阅』那个按钮」「想用峰月律さん 的方式来做」（＝联动到队友峰月律 的页面／表情），弹幕同步刷「国民人数」。这一段没有实质内容，但把**「国王／国民」话术的日常使用**露了出来——她叫观众「国民」，自称国王，观众也回「**おかえりなさいませ**」（欢迎回来，23:44:14）。

饮料是这一场的小插曲：她拿出的是**コカ・コーラ**（可口可乐），于是弹幕陷入混乱——「不是百事吗！！！😭」「居然在跟可乐出轨…」「百事『怎么会这样』」「百事派的我，震怒」。她的回答是「今天很遗憾，今天不是百事」「不过已经快喝完了」。

## 2. 「課題」の告発：ストロークと、ライブで簡単にしていた話

她开场就把本场的主题钉死：**扫弦（ストローク）是超级课题，左手也是课题**，刚才她完全做不到。「課題」这两个字随后被她连说了十几遍，弹幕把它接成一场读音梗（「か・だ・い」「過大！」「架台？」「金井」「口条也算课题吧」）。观众那边也在同步点名（「扫弦回」「切音很重要呢」）。

真正有信息量的是她对自己编曲的告白：**她在 Live 上弹的那一段，其实是自己降过难度的版本**——不放节拍器那样弹的时候，她在 Live 上就是那样弹的，可「那其实是不对的」。原因是十六分音符的「ちゃんちゃかちゃらー」（恰咔恰咔恰啦——）型的部分又难又快：慢的时候能放松地弹出来，快的时候就弹不了，练到实在弹不出来，啪嗒掉了眼泪。所以她把那段改成了**八分音符**（原本也有十六分的部分），并说**ビッグマウス**（Big Mouth）的十六分「算是极限」——那就是她的上限，而最终目标是「其实想用十六分弹」。

中段她还调出一份谱面来对速度（读出的 BPM 是 195）。

## 3. できない原因：手首のひねりすぎと、血まみれの左手

她把自己弹不出来的原因拆得很细，这一段是本场的"自我介绍"：

- **手腕拧过头**：她比划着说「大概就是这样，就这样这样这样地拨」「这个手腕这样拧着，然后这个做过头了」。
- **左手被磨得血肉模糊**：磨得特别厉害的不是指甲，而是指甲根部会被磨掉，现在已经结了痂。弹幕「好惨..」「光听就觉得疼的那种」「血肉模糊 w」。这也解释了本场弹幕为何大量出现她 X 显示名里的 **🐰🩹**（见 §7）。
- **上拨时被卡住、节奏发跳**：往下拨还好，往上拨的时候会卡住，所以往上拨需要力气，上不来，就有点跳——这正是**制作人（プロデューサー）**后来指出过的毛病（见 §9）。
- **弹幕的流派论**：一位观众提供了经验谈——以前弹的时候，八分用肘、十六分用手腕，她当场被点醒：「真有那种弹法啊」「我被教的是『小的部分就小动作地做』，是那种感觉吗」——**这条弹幕后来成了本场后半的练习方针**（＝放开肘）。

## 4. 初心者论：ドミソが押さえられなかった頃と、ファーストライブの後

弹幕来了两位初見（第一次来的人；其中一位说「我是一周前才开始弹吉他的新手」），由此引出一段成体系的自我考古。

- **「新手」这个自称能叫到什么时候**：她自问「ののちゃん 呢，算是刚开始弹吉他吧……『新手』这个名号可以叫到什么时候呢？」，又补一句「已经 1 年了嘛」——观众的答案很宽（「第一年还行吧 w」「能享受新手福利的期间都 OK」「自己满意为止 w」「我大概当了 30 年新手」）。
- **按不住ドミソ（C 和弦）**：以前那个叫 C 和弦的、这个ドミソ……她首先就按不住，一开始就是，现在也不行——「ののちゃん 是新手啊」。弹幕同步把这句按谱面翻成「是 5 弦 3 品那个吧 w」。她说讲这些是**为了给新手打气**。
- **已经放弃过一次**：在开始现在这个之前，吉他已经放弃过一次——声音出不来，变成「ぺんぺんぺんぺんぺん」，心折了就不练了，弹幕配合刷「ﾍﾟﾝﾍﾟﾝﾍﾟﾝﾍﾟﾝ」。她的自我诊断是「啊，我没天分——觉得弹吉他的人好厉害，就放弃了」，后来「练着练着，就变得能按下去了」。
- **害怕换弦**：最初的ののちゃん 呢，那个换弦，想着手会不会被割破，那个也很怕——弹幕一片"常有的事"式的共鸣。

**首场 Live 之后的心态**是本场最像"宣言"的一段：

> 「こんなもんかって思われたくないから。」
>
> 因为不想被觉得"就这样而已"。

她把理由讲全：因为想着「不管是做得到还是做不到，正式演出都会到来」，既然如此，那就绝对要变得超厉害——不是变得做得到之后，就不想做正式演出，所以「要更努力」。

**向上心的延伸**：最初的ののちゃん 连ドミソ 都按不住，当时想「不可能变得能弹（穿）这种衣服」，但后来能弹出声了；看着那些超绝技巧的吉他手，虽然也会想「这种帕拉林、きゅりゅりゅきゅー 怎么可能弹得了」，但「当时觉得做不到的事，正在变得做得到，所以说不定也能变得做得到」。观众以「成长空间长」「Live 上的ののちゃん 超帅」回应，她接住玩了一下：「我是『成长空间长』。」

## 5. 髪とお団子

上半段的收尾是一段很短的生活话题：她今天**把头发扎成了丸子头（お団子）**，但镜头会**时不时拍到头发**，于是当场「解除丸子头」——弹幕一排「解除丸子头！」「丸子头解除圈」。理由是「今天头发有点干枯」，所以她决定「保密」。

## 6. メトロノーム音量事故と「ザオリク」

节拍器一开，音量事故当场发生——她在调音时把节拍器放到了极大声（「刚才超响的吧」），于是：

> 「ごめん、みんな死んだ。……勝手に殺すんじゃない。」
>
> 抱歉，大家死了。……别随便把人杀掉啊。

弹幕配合集体阵亡（「死了」「差一点就致命伤」「国民动不动就死」「撑住了」），她则宣布国王可以复活国民——「国王来复活你们哦」「ののちゃん王国 的国王的箱庭。虽然把咒语忘了——复活吧、复活吧」，弹幕接着刷「ザオリク」（复活咒文）「ザオラル」「活过来了」「别随便对待国民！(笑)」。随后确认音量，宣布今晚只想练扫弦，正式进入练习段。

## 7. 練習段前半：肘を外す・横から写す・立って弾く

从这里起大约 **50 分钟**几乎是纯练习（无伴奏、只有节拍器），她一边弹一边自言自语，观众则以固定应援刷屏——**「🎶🐰🩹🎶🐰🩹🎶」**（本场 🐰 115 条／🩹 112 条，正是她 X 显示名「宮永ののか🐰🩹」的那对记号），另有「ないすぱ」（收到 SC 时的连呼）35 条。可整理出的方法论有六条。

1. **从第 1 次起就是"抚摸式"地碰弦**：这个肘部拨弦她没做过，反而想从这里试试；看第 1 次（那场）就明白，从第 1 次开始她就是这样、像抚摸一样地做——因此她想试试**动肘**、把拨片**笔直地碰弦**。
2. **老师的指示是"竖着"**：要再竖着一点，不竖着不行，声音会出现差别（下拨和上拨的声音不同）。弹幕补了一句很准的诊断：「上拨的时候不是垂直，而是画着弧线在弹，所以声音才会不稳」，她同意「大概就是这么回事」。
3. **把摄像机当镜子**：她当场想到——摄像机正好拍得到，那就用它看自己的姿势，像镜子一样不就好了。弹幕「想到好主意了」「聪明」。随后又发现**横向机位更好懂**。
4. **厉害的人手腕是折着的**：看厉害的人的弹法，手腕是折着的；ののちゃん 是直的。「到底是哪里不一样呢」——她承认「那个我首先就不太懂」。
5. **放开肘**（＝上节那条观众经验谈）：贴着也好不贴也好大概都一样，但确实是贴着，所以感觉是在这里这样做了。弹幕给出建议（搜「カッティング 手首」（切音 手腕）的视频、好像会因吉他的形状而异、自己弹空气吉他的时候是离着的等）。她的结论是**不强行外**、但**要改掉把重心压在肘上的习惯**。
6. **站着弹**：一站起来立刻发现——「啊，肘没贴着。站着的时候肘没贴。所以坐着的时候才不好弹吗」，并感叹「站着的时候和坐着的时候，做的是不一样的事呢」，同时也自嘲「还有脸是僵的」。

至于成果，她给的评价相当不客气：「嗯，不能一招解决」「总之很难」「发出很重的隆隆声」「完全无视节拍器」，并发现一个新问题——**停音的时候会出声**（「这个，停的时候这样出声是对的吗？有点在意」）。

## 8. 「この配信、先生に見てもらおう」

由上面那个「停音时的声音」引出一个**把直播当工具用**的想法：把这个（直播画面）拿去给老师看——「这个对吗」「这个止音（闷音）的方式对吗」，这样问，让他说「不对」。

她的解释是：给老师看的时候会放（这段直播）哦，大家的评论也会一起过去——**直播留下了可以给老师看的证据**。弹幕配合演出「耶——！老师在看吗〜？」「拿去给老师看吧」「直播的划时代用法！」「在意的部分能留在直播里，真好」，也有人替老师配音（「老师『诶…』」「老师｛这是什么啊…｝」）。她还预告了老师可能的反应：「老师也没想到会被搭话吧」「会变成『这是什么啊』」。

## 9. 16 分を「均等に刻む」練習：ビッグマウスのコードで 120→130→100→200

**ビッグマウス**（Big Mouth）的副歌被当成终极练习素材：用它的副歌练，只要那里能把十六分弹出来，到哪里都能通用。

实际做法是**不弹曲子、只按ビッグマウス 的和弦（コード）持续刻十六分**——在弹曲子之前，先用它的和弦一直弹十六分更好。她按节拍器一个档一个档地试：

| BPM      | 她的评价                                                                                  |
| -------- | ----------------------------------------------------------------------------------------- |
| 120      | 「这里 120 哦」→「不过 120 是做得到的呢」                                                 |
| 125      | 「在 125 上凑上了」                                                                       |
| 130      | 「那 130……有点悬」                                                                        |
| 100      | 「今天先用 100 来。用 100 做完就睡」                                                      |
| 200      | 一度把速度跳到 200（「诶等等，用 200 来」「200 OK」）→ 弹不了又退回来（视频内 0:41 前后） |
| 109／110 | 「大概 100、109、110 左右」                                                               |
| 103      | 「等等，103、120 也试试看」                                                               |

这个练习让她得出本场最重要的自评：

> 「ののちゃんにはまだね、リズムを刻むなんてことは早かったですね。もっと、あの、全ての音を均等に刻めるようになるところから始めなければならなかった。悟りました。」
>
> 对她来说呢，"刻节奏"这件事还太早了。应该，那个，从"能把所有音都均匀地刻出来"的地方开始才行。……我悟了。

问题被弹幕点破得很准：**会听到弦被刮到的声音**（「特别，会有那种弦被（拨片）刮到的声音。不好」）；她还用拟声形容自己的失败形态——「タンカタンカ」「ちゃんこちゃんこ」，以及那种「たンかタンかン」的感觉：总像是变成了跳舞，而她想把它变成「タカタカ」，「这就是课题」。

不过她也注意到改善：「确实比刚才流畅了」「路还很长」，并给了一句很她的收束：**不顺的日子就是不顺，但还是课题；大概知道怎么才能解决这个课题了**。

## 10. 「プロデューサーはわかるんだ」＝ リズムの跳ねを見抜かれた話

由「ちゃんこちゃんこ」直接引出一段事件回顾：她最感动的是「这个节奏不均匀」这件事，是被制作人当面说的——「ののかさん，那个，最近节奏是不是有点『タンカタンカ』？像那样，是不是在跳」，她只能回「是，就是在跳呢——」。就是在跳。她还想着「跳这件事暴露了」。制作人好厉害啊。

弹幕立刻把它做成称呼——「不愧是制作人」「不愧 P」「露馅了吧」「制作人真懂啊」。

## 11. メンバーシップ构想と「パジャマ詐欺じゃない」論

**练习效率的发现**：她认为**直播本身提高了她的集中力**——开着直播的话专注力特别高，今天也是，「这样练是不是更好？」之类的办法**找到了**，所以效率很高，超高。

由此她抛出一个**还没和运营谈过**的构想：

- **让会员陪她练基础**：希望会员早点开始，然后每天都让大家陪她做基础练习；
- **形态**：在公开枠做的话会变成「这样合适吗」，所以不是实拍，而是那种「虽然穿着睡衣，来播一下吧」的感觉，**不开摄像头，一边基础练习一边杂谈**——在会员里更好做；
- **留白**：不过并没有跟运营商量过会员要做什么，只是她自己随便想的。

弹幕对这一段的反应极热（「会员是不是快开始了？」「每天练基础帮大忙了」「我陪你」「陪你多久都行！」）。

接着「睡衣（パジャマ）」两个字把话题带偏成一场相声：

- 她先划界：再怎么说，穿着睡衣，那个，不开摄像头；不开的……不穿睡衣的；
- 弹幕立刻反问「为什么洗澡可以、睡衣就不行」，她只回「诶，是『脱』哦。睡衣再怎么说（不行）」；
- 随后是**「不给看，但想看就订阅」**的自我拆台：想看睡衣的人请订阅频道 → 就算订阅了，睡衣也不给看 → 不给看，但想看就订阅。诈骗、是诈骗 → 又立刻辩解：说了「不给看」、说了「不给看」，所以不是诈骗；
- 弹幕把它接成一句口号：「玄米的不存在应援『不是诈骗！』」；
- 她顺着这个逻辑把自己逗笑：反过来说，穿睡衣直播是不是能涨订阅？→ 可是我也没有能给大家看的那种可爱睡衣啊。去买吗。

## 12. ★ フリーチャット「ネタツイの墓場」を作る（本场最重的一段）

弹幕一句「这里是 Twitter 吗」让整场转向：

> 「ののちゃんのコメント欄もネタツイートの墓場にして、え、それかさ、あの、ネタツイートの墓場っていうフリーチャット作ろうか。今、今作ってあげるね。」
>
> 把评论区也当成段子推的墓场，诶，或者呢，那个，要不要做一个叫「段子推的墓地」的自由聊天？现在，现在就给你做哦。

她说做就做，**当场在直播里把自由聊天建了出来**（视频内 **t≈1:20:15**）。可还原的创建过程：

| 步骤     | 她的操作／发言                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------ |
| 命名     | 「ネタツイートの墓場」（段子推的墓地）；「那个，请扔到墓场里」「大家把关于她的段子，那个，扔到墓场里」 |
| 类别     | 「类别就给你设成娱乐（エンターテイメント）」                                                           |
| 缩略图   | 「缩略图大家觉得什么好？」→「就用あられちゃん帮我画的那张」                                            |
| 年龄设定 | 「诶，不是面向儿童的」                                                                                 |
| 收款     | 「收益呢，呃，不太清楚」                                                                               |
| 终了日   | 「呃，这个设到最远就行了吧。到什么时候来着？」                                                         |
